# belajar html

hari ini saya melanjutkan pembelajaran website melalui w3schools.

saya memepelajari cara untuk membuat list di html seperti berikut menggunakan tag `<ul>` dan `<li>`
```
<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
```

memebuat list dengan nomor menggunakan tag `<ol>` dan `<li>`
```
<ol>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ol>
```

memebuat list deskripsi menggunakan tag `<dl> <dt> <dd>`
```
<dl>
  <dt>Coffee</dt>
  <dd>- black hot drink</dd>
  <dt>Milk</dt>
  <dd>- white cold drink</dd>
</dl>
```
