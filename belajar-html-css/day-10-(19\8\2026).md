# belajar html

hari ini saya melanjutkan pembelajaran html saya di website w3schools.

cara membuat border dengan styles
```
<p style="border: 1px solid black">Hello World</p>
<div style="border: 1px solid black">Hello World</div>
```

membuat border di tengah paragraf
```
<p>This is an inline span <span style="border: 1px solid black">Hello World</span> element inside a paragraph.</p>
```

pewarnaan background dengan tag `<div>`
```
<div style="background-color:black;color:white;padding:20px;">
  <h2>London</h2>
  <p>London is the capital city of England. It is the most populous city in the United Kingdom, with a metropolitan area of over 13 million inhabitants.</p>
</div>
```

pewarnaan huruf di tengah paragraf
```
<p>My mother has <span style="color:blue;font-weight:bold;">blue</span> eyes and my father has <span style="color:darkolivegreen;font-weight:bold;">dark green</span> eyes.</p>
```
