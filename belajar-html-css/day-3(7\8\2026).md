# belajar html

hari ini saya melanjutkan belajar html di website w3schools, yaitu saya mencoba untuk mengubah backgroud seperti berikut.
```
<body style="background-color:powderblue;">

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
```

```
<body>

<h1 style="background-color:powderblue;">This is a heading</h1>
<p style="background-color:tomato;">This is a paragraph.</p>

</body>
```

saya juga belajar untuk mengganti font tulisan pada html seperti berikut
```
<b> - Bold text
<strong> - Important text
<i> - Italic text
<em> - Emphasized text
<mark> - Marked text
<small> - Smaller text
<del> - Deleted text
<ins> - Inserted text
<sub> - Subscript text
<sup> - Superscript text
```

dan contohnya sebagai berikut untuk bold
```
 <b>This text is bold</b>
```

contoh untuk important text
```
 <strong>This text is important!</strong>
```
