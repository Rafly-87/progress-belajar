# belajar html css

hari ini saya melanjutkan pembelajaran saya di website w3schools

saya mencoba membuat inline css di html sperti berikut
```
<h1 style="color:blue;">A Blue Heading</h1>

<p style="color:red;">A red paragraph.</p>
```

selain itu saya juga belajar untuk membuat external css pada html seperti berikut
```
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>
```

apa yang saya lakukan sebelumnya styles di html yang jika di dalam css dapat dibuat sebagai berikut
```
body {
  background-color: powderblue;
}
h1 {
  color: blue;
}
p {
  color: red;
}
```
