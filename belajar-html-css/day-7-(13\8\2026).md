# belajar html

hari ini saya belajar html melalui website w3schools dan saya mempelajari bagaimana untuk menambahkan link
```
 <a href="https://www.w3schools.com/">Visit W3Schools.com!</a>
```

dan juga bagaimana menambahkan link untuk di buka di tab baru
```
<a href="https://www.w3schools.com/" target="_blank">Visit W3Schools!</a>
```

cara untuk membuat link mwnjadi gambar
```
<a href="default.asp"><img src="smiley.gif" alt="HTML tutorial" style="width:42px;height:42px;"></a>
```

cara menambahkan link untuk email
```
 <a href="mailto:someone@example.com">Send email</a>
```

menambahkan link sebagai tombol
```
<button onclick="document.location='default.asp'">HTML Tutorial</button>
```
