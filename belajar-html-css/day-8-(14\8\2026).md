# belajar html

hari ini saya memepelajari tag html untuk menambahkan gambar yaitu `<img>` dengan contoh sebagai berikut

```
 <img src="img_girl.jpg" alt="Girl in a jacket">
```

dalam tag tersebut terdapat atribut seperti `src` dan `alt`
src - Menentukan jalur ke gambar
alt - Menentukan teks alternatif untuk gambar

terdapat juga atribut `style` untuk menyesuaikan ukuran gambar yang ingin dimasukkan

```
 <img src="img_girl.jpg" alt="Girl in a jacket" style="width:500px;height:600px;">
```

dapat juga menjadikan gambar untuk di klik menjadi link seperti berikut

```
<a href="default.asp">
  <img src="smiley.gif" alt="HTML tutorial" style="width:42px;height:42px;">
</a>
```
