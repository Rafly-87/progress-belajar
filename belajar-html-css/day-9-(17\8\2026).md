# belajar html

hari ini saya meanjutukan pemebelajaran html saya di website w3schools, dan sekarang saya belajar untuk membuar tabel pada html seperti berikut.

```
<table>
  <tr>
    <th>Nama</th>
    <th>Nomor</th>
    <th>Asal</th>
  </tr>
  <tr>
    <td>Yantoe</td>
    <td>6969</td>
    <td>Solo</td>
  </tr>
  <tr>
    <td>Yanti</td>
    <td>8888</td>
    <td>Bogor</td>
  </tr>
</table>
```

pada tag untuk membuat tabel, terdapat tag lain seperti `<tr>` untuk membuta baris pada tabel dan tag `<td>` untuk memuat isi pada tabel.
Terdapat juga tag `<th>` untuk membuat headers di cell pada tabel
